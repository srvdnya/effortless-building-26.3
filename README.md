# Effortless Building — Minecraft 26.3 Unofficial Port

An unofficial Minecraft 26.3 compatibility port of **Effortless Building 4.3** by **Requioss**.

This project updates the 26.2 version of Effortless Building to work with Minecraft Java 26.3 / Fabric.

> **This is not an official release of Effortless Building.**
> The original mod was created by Requioss.

## What was updated

- Minecraft 26.3 input system compatibility
- Left Alt radial menu
- Radial menu GUI rendering
- Mouse/input handling
- Minecraft 26.3 GUI rendering changes
- Multiplayer compatibility
- Compatibility with Paper 26.3 through a separate server bridge

## Requirements

- Minecraft Java Edition 26.3
- Fabric Loader
- Fabric API

For Paper servers, the separate **Effortless Building Paper Bridge 26.3** is required.

## Installation

1. Install Fabric for Minecraft 26.3.
2. Install Fabric API.
3. Download the latest 26.3 release from the **Releases** page.
4. Place the Effortless Building JAR in your `mods` folder.
5. Launch Minecraft.

### Paper Server

If you are connecting to a Paper 26.3 server, install the separate:

**Effortless Building Paper Bridge 26.3**

The Paper bridge is maintained in a separate repository.
